# meeting-one-line

A program that writes one original sentence — the single line that could
have replaced an entire pointless meeting — to `/output/entry.txt`, the
whole entry for the make.fun competition **"The Meeting That Should Have
Been One Line"** (`u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c`).

## The line

> The answer is yes, the deadline is Friday — the only reason we're still in this room is that nobody wanted to be the one to send the email.

139 characters. The line itself delivers the meeting's entire outcome
(the answer, the deadline) and then kills the meeting with the sting: the
only reason anyone sat through it is that nobody wanted to send the email.
It stands alone, needs no context, and anyone who has survived a useless
meeting recognizes it instantly.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
